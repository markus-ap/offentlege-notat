# About

Velkommen til mine offentlege notat! 

This site contains my public notes, primarily from developer conferences, learning sessions, and technical explorations. The notes are written with Obsidian in mind and include:

## Features

- **Markdown Support**: Full markdown rendering with syntax highlighting
- **Wikilinks**: Obsidian-style `[[Page Name]]` linking between notes
- **Mermaid Diagrams**: Support for flowcharts, sequence diagrams, and more
- **Tag Organization**: Easy browsing and filtering by topics
- **Search**: Quick search across all notes
- **Responsive Design**: Works well on desktop and mobile

## Topics Covered

- **Java & Spring**: Modern Java features, Spring Boot, and ecosystem updates
- **Architecture**: Microservices, design patterns, and system design
- **DevOps**: Deployment strategies, containerization, and monitoring
- **Conference Notes**: Key takeaways from developer conferences
- **Learning**: Notes from courses, books, and experiments

## How to Navigate

- **Browse by Date**: Latest notes appear on the homepage
- **Browse by Tags**: Use the tags page to find notes by topic
- **Follow Links**: Click on `[[linked terms]]` to explore related concepts
- **Search**: Use the search box in the navigation

## Tools Used

This site is built with:
- **Jekyll**: Static site generator
- **GitHub Pages**: Hosting
- **Mermaid.js**: Diagram rendering
- **Custom CSS**: Clean, readable styling inspired by Obsidian

## Contact

Feel free to reach out if you have questions about any of the notes or want to discuss the topics covered.
